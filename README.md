#  Análisis de Ventas — Tienda Minorista
> Proyecto de análisis de datos para entender el comportamiento de ventas y tomar decisiones comerciales.

##  Descripción
Se analizaron más de 9.800 registros de ventas para identificar: categorías más rentables, estacionalidad mensual y regiones con mayor rendimiento.

##  Tecnologías
- **Python** — Procesamiento de datos
- **Pandas** — Limpieza y manipulación
- **Matplotlib & Seaborn** — Visualización
- **Jupyter Notebook** — Entorno de desarrollo
